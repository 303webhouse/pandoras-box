QS-01 — Phase 0 census: schema ground truth, watermarks, activity map
Purpose: (a) authoritative column-level schema for the analysis tables;
(b) rowcounts + id/time watermarks (id ranges are the shift-immune keys
while P1 is unresolved); (c) IF GATE PASSES: strategy roster, per-strategy
monthly + daily signal census, outcome-resolution coverage (P3/P9 gates).
Caveat: created_at in signals/signal_outcomes is UNTESTED for the P1 six-
hour shift. Month/day bucketing tolerates ±6h except boundary rows; all
Block C output is labeled DEGRADED-pending-P1-test. This is a census, not
a hypothesis test — no pre-registration required; template files alongside.

-- QS-01-A1: table inventory
SELECT table_name
FROM information_schema.tables
WHERE table_schema = 'public' AND table_type = 'BASE TABLE'
ORDER BY table_name
LIMIT 300;

-- QS-01-A2: column ground truth for analysis tables
SELECT table_name, ordinal_position, column_name, data_type, is_nullable
FROM information_schema.columns
WHERE table_schema = 'public'
  AND table_name IN ('signals','signal_outcomes','unified_positions',
                     'bias_composite_history','factor_readings',
                     'stable_metrics','balance_snapshots')
ORDER BY table_name, ordinal_position
LIMIT 600;

-- QS-01-B1
SELECT 'signals' AS tbl, COUNT(*) AS n_rows, MIN(id) AS min_id,
       MAX(id) AS max_id, MIN(created_at) AS min_ts, MAX(created_at) AS max_ts
FROM signals;

-- QS-01-B2
SELECT 'signal_outcomes' AS tbl, COUNT(*) AS n_rows, MIN(id) AS min_id,
       MAX(id) AS max_id, MIN(created_at) AS min_ts, MAX(created_at) AS max_ts
FROM signal_outcomes;

-- QS-01-B3
SELECT 'bias_composite_history' AS tbl, COUNT(*) AS n_rows, MIN(id) AS min_id,
       MAX(id) AS max_id, MIN(created_at) AS min_ts, MAX(created_at) AS max_ts
FROM bias_composite_history;

-- QS-01-B4
SELECT 'unified_positions' AS tbl, COUNT(*) AS n_rows FROM unified_positions;

-- QS-01-B5
SELECT 'stable_metrics' AS tbl, COUNT(*) AS n_rows FROM stable_metrics;

-- QS-01-B6
SELECT 'factor_readings' AS tbl, COUNT(*) AS n_rows FROM factor_readings;

GATE FOR BLOCK C (mechanical check, no judgment): run C0–C3 ONLY IF the
A2 output lists ALL FIVE of: signals.id, signals.strategy,
signals.direction, signals.created_at, signal_outcomes.signal_id.
If any is absent: SKIP Block C entirely, return A+B only, and state which
column(s) were missing. EDGE will issue QS-02 keyed to the real schema.

-- QS-01-C0: authoritative strategy roster (verify, don't inherit)
SELECT strategy, COUNT(*) AS n
FROM signals GROUP BY 1 ORDER BY 2 DESC LIMIT 100;

-- QS-01-C1: per-strategy, per-direction monthly census (full history)
SELECT strategy, direction, DATE_TRUNC('month', created_at) AS month,
       COUNT(*) AS n
FROM signals GROUP BY 1, 2, 3 ORDER BY 1, 2, 3 LIMIT 2000;

-- QS-01-C2: daily census, alert-crash window resolution
SELECT strategy, DATE_TRUNC('day', created_at) AS day, COUNT(*) AS n
FROM signals
WHERE created_at >= '2026-06-15'
GROUP BY 1, 2 ORDER BY 1, 2 LIMIT 3000;

-- QS-01-C3: outcome-resolution coverage per strategy (P9)
SELECT s.strategy, COUNT(*) AS n_signals,
       COUNT(DISTINCT o.signal_id) AS n_resolved,
       ROUND(100.0 * COUNT(DISTINCT o.signal_id) / NULLIF(COUNT(*),0), 1)
         AS pct_resolved
FROM signals s
LEFT JOIN signal_outcomes o ON o.signal_id = s.id
GROUP BY 1 ORDER BY 2 DESC LIMIT 100;

END QS-01
