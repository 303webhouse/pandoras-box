Every label on this page is the display name the hub would serve. The internal database keys are deliberately not shown anywhere, including here.
Accounts are not colour-coded on purpose. On this page lime already means a gain, vermilion a loss and amber “we cannot confirm this”; giving each account its own colour would teach a second meaning for the same three. The name identifies the account, and teal marks only the one you are filtered to. Say the word if you would rather have fixed colours.
